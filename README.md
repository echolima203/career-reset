# Career Reset

Marketing / advertising site for **Career Reset** — an app to support career progression.

Static site, deployed via **AWS Amplify** (connected to this GitHub repo's `main` branch).

## Getting started

Drop the site files into this folder (e.g. `index.html`, `images/`, `styles.css`),
then commit and push:

```bash
git add .
git commit -m "Add site files"
git push
```

Amplify will rebuild and deploy automatically on each push to `main`.
